# CVCS_EAD_2271764 • Projeto Integrador Transdisciplinar em Ciência da Computação 

# Objetivo

Fazer o Catálogo de Livros, Séries e Filmes (Java, Servlets, JSP e
PostgreSQL) sem concatenar string em SQL, usando
PreparedStatement no padrão DAO, e provar com teste que a busca
não deixa uma entrada maliciosa virar comando.

# Como rodar

```bash
cd projeto
docker compose up --build
```

acesse: http://localhost:8080/catalogo
